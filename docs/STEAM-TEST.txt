TRMP 0.6.0-alpha.1 - EXPERIMENTAL STEAM TEST

This public alpha includes invite acceptance and a Steam relay transport.
It is not yet validated between separate Steam accounts/machines. The older
0.5.1 release is local-only. Read START-HERE.txt; no Git/GitHub account is
needed for downloading/installing this alpha.

REMOTE TEST SETUP (requires two legitimate, signed-in Steam peers)
1. Install this same development package on both Windows PCs. Both must have
   the compatible game/content. Installation keeps separate copied profiles.
2. Open Launch-Mod.cmd in each installed mod folder. Both players choose
   "Steam Versus (experimental)". Keep the mod running at its main menu.
3. Host: Play > Play Versus. Create the private lobby and select a friend in
   Steam's own invitation dialog. The mod never chooses/sends invitations to
   your friends automatically.
4. Receiver: accept that invitation in Steam while the isolated mod is open.
   The running mod joins the invited lobby and checks its owner, membership,
   protocol and build/content fingerprint before attempting a Steam link.
5. Host: choose START INFILTRATOR MISSION in the Versus panel. Follow the
   original Infiltrator prompts, difficulty, loading screen and intro.
6. Once the native mission/listener and authenticated relay are ready, the
   receiver automatically connects through its local proxy. Confirm native
   loading screens with Enter. The receiver controls an original bunker NPC.
7. Verify independent control, both damage directions/results and the host's
   native Restart Mission / Repeat. Restart metadata is carried by the Steam
   lobby and old-generation game packets are discarded.

LOCAL EVIDENCE (2026-11-10)
The real game completed a two-instance socket-pair tunnel test: engine join,
separate character movement, defender fire, native Infiltrator death and the
defender's MISSION SUCCESS. A separate Steam-mode launch created a private
lobby and P2P listener; authentication and relay availability both reported
Current. The Versus start button opened the original mission prompts.
Invite acceptance and remote relay routing still require two actual peers.

Invites accepted during an active mission wait for the main menu. This build
does not redirect Steam's cold-start launch of the ORIGINAL game into the mod.
Start the isolated mod first. A host process/connection loss aborts this test
party; there is no host migration or seamless mid-mission reconnection.

TRANSPORT / LIMITS
The engine's IP driver stays bound to 127.0.0.1. It talks locally to a bounded
UDP proxy; game datagrams travel between peers through SteamNetworkingSockets.
ICE/direct candidates are disabled, encryption is required, and each data
pump checks authenticated/relayed flags. There is no direct-IP fallback if
relay setup fails. An unrelated Steam identity is rejected before engine data
is forwarded. Only the other member of the two-person party is accepted.

The compatibility fingerprint includes mod code/DLL hashes and game PAK
filenames/sizes plus the supported executable identity. It detects mixed
packages/content metadata; it is not an anti-cheat or full PAK integrity audit.
The inherited engine RPC surface and player-host trust still need review.
Internet/real-peer IP privacy is not certified by a local socket-pair test.

DEVELOPER LOCAL TRANSPORT CHECK (one PC/account)
Launch-Mod.ps1 -Role host -Transport tunnel_test
Launch-Mod.ps1 -Role client -Transport tunnel_test
Start the host's original Infiltrator mission, then Join player two normally.
This mode tunnels the real engine UDP through an actual Steam socket pair
inside the host process. It exercises the transport code and two-instance
gameplay without claiming Internet connectivity or relay routing. Port7778 is
reserved for that local proxy. Do not run a second tunnel host concurrently.

Diagnostics remain in the isolated runtime profiles. Do not publish saves,
credentials, raw crash dumps or unreviewed logs. Use FEEDBACK-TEMPLATE.txt for
reports. A separate-account remote test is still required before calling this
an Internet-ready release.
