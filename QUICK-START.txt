RESISTANCE MULTIPLAYER (TRMP) - 0.6.0-alpha.1
WINDOWS / STEAM - EXPERIMENTAL PUBLIC ALPHA

No Git or GitHub account is needed to download/install. Use the INSTALLER ZIP,
not GitHub's automatic 'Source code' ZIP. START-HERE.txt is the short guide.

READ THIS FIRST
Includes Steam invite acceptance, relay-only transport code and local crash
reporting. Actual Internet play between TWO DIFFERENT Steam accounts/PCs has
NOT yet been tested. This alpha asks volunteers to test that flow. Do not
assume a local socket-pair test proves Internet play or IP privacy.
Default local play uses two instances on one PC with focused-window control;
it is not split-screen or simultaneous two-controller couch PvP.

REQUIREMENTS
- Legitimately installed compatible Steam Windows game and Infiltrator assets.
- Installer checks the supported executable SHA256 and rejects other builds.
- Internet access to download the pinned official UE4SS dependency.
- Internet test: one game install and signed-in Steam account on EACH PC;
  both testers install the SAME alpha ZIP. No Git/developer tools required.
- Local test: capacity to run two game instances; minimum hardware unmeasured.

INSTALL / UPDATE
1. Close existing mod games. Extract ALL files from the installer ZIP.
2. Double-click Install-Mod.cmd and wait for completion. It prepares separate
   game copies and copied save profiles; it does not overwrite original saves.
3. The INSTALLED mod folder opens. Run Launch-Mod.cmd THERE, not in the
   extracted download folder. Default: %LOCALAPPDATA%\TRMP-LocalPreview.
4. Existing copied profiles survive updates. Do not install into the original
   game folder or manually forward/open the engine port on your router.

STEAM INTERNET TEST (NOT YET VERIFIED REMOTELY)
1. BOTH players choose 'Steam Versus (experimental)' in their installed launcher
   and leave the mod running at its main menu. See docs/STEAM-TEST.txt.
2. Host: Play > Play Versus. Choose your friend in the Steam overlay dialog.
3. Friend: accept while the isolated mod is ALREADY OPEN at its main menu.
4. Host: START INFILTRATOR MISSION. Follow the original prompts/difficulty,
   finish loading with Enter, watch the intro and allow automatic hosting.
5. Receiver should join automatically after the mission and Steam link are
   ready. Confirm loading with Enter (also if the screen stays pale/white).
   Allow another15 seconds for player/body setup. Report where it fails.
6. Test independent movement, hands, damage, results, native Restart Mission
   / Repeat and rejoin. These end-to-end steps are still unverified remotely.
Cold Steam invite launch into the original game is NOT redirected to this
mod. There is no host migration or seamless recovery after host process loss.

LOCAL TEST (ONE PC; NO FRIEND/SECOND ACCOUNT NEEDED)
1. Choose 'Start Infiltrator mission host'. In game: Play > New Infiltrator
   Mode, original prompts, Normal, Enter after loading and the original intro.
   Wait about15 seconds more for automatic hosting.
2. Choose 'Play a Resistance NPC', then 'Join player two'. Finish loading
   with Enter, including a pale/white loading screen. Allow setup to finish.
3. Focus each game window to control that character: LMB fire, RMB aim, R reload.
'Host loaded save' is for the older campaign arena experiment, not Infiltrator.

SCENARIO / RESULTS
Host plays the native Infiltrator and its original objectives. Defender takes
over one existing bunker Resistance soldier; other NPCs remain AI. PvP is first
person. Infiltrator completion => Resistance MISSION FAILED. Stopping the
Infiltrator => Resistance MISSION SUCCESS. Killing the controlled soldier
eliminates that defender without respawn and does not alone finish the mission.
Native Restart Mission / Repeat creates another mission; local automatic
defender rejoin was tested. Loading screens and the intro repeat.

UNTESTED / UNSUPPORTED
Separate-account invite delivery, WAN relay routing/privacy, remote damage/
results/restart/rejoin across routers, long full missions, extended stability,
multiple hardware/game editions and security of inherited engine RPCs need
testing. More than2 players, host migration, cold invite launch, split-screen,
simultaneous couch controls and finished campaign co-op are not supported.
Resistance ultravision/full Terminator scanning, NPC animations/ragdolls,
ammo behavior and visual polish are unfinished. No anti-cheat/unhackable claim.

REPORTING / PRIVACY
Diagnostic reports are prepared LOCALLY, never automatically uploaded. Use
'Diagnostic reports' in the launcher to review a report and Open report folder.
Send only the generated .txt through your chosen announced reporting channel.
GitHub is optional; Steam replies can give version/signature/reproduction steps.
See REPORT-A-BUG.txt. GitHub/Steam posts are public. Never post raw logs, dumps,
crash XML, saves or credentials. Untick local report preparation to disable it
for a launch. Full details: docs/DIAGNOSTICS-PRIVACY.txt.

REMOVE
Close mod games and remove only the separate installed TRMP-LocalPreview
folder. The original game/saves are outside it. This is an unofficial mod,
not affiliated with the game's developers/publisher. No game content or save
is bundled. See THIRD-PARTY-NOTICES.txt for dependencies/licensing.
